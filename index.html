About

Hi — I'm Johan. I like software that is small enough to understand and fast enough to disappear. This site is where I keep the tools I got tired of looking for.

Everything is plain HTML, CSS, and JavaScript — no framework, no build step, no tracking. The whole site is a handful of files you can read in an afternoon, and it deploys straight to GitHub Pages on every push.
